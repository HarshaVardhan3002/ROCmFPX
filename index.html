Low-bit LLMs for AMD GPUs

Frontier-size models on one 128 GB Strix Halo machine

ROCmFPX is a llama.cpp fork tuned for AMD GPUs, especially the Ryzen AI Max+ 395 (Strix Halo). The goal: run the big open models at home, at a quality you can actually use.

This is a first iteration. The current releases fit big models into 128 GB by removing the least-used experts and using existing 1 to 2 bit quantizations. That works, but it costs quality.

We are actively working on new ROCmFPX formats at around 2.1 bits per weight and below 2 bits that keep much more of the original quality and run fast on AMD GPUs. This will take time, and we need the community's help: testing on real hardware, reporting results, and telling us which models matter to you.

How you can help

  • Run a release on your AMD machine and post what you see: speed (llama-bench output), memory use, and whether the answers are good. Use the Community tab of the model on Hugging Face or a GitHub issue.
  • Tell us your hardware: Strix Halo, Radeon RX 7000 / 9000, Instinct, Windows or Linux, Vulkan or ROCm.
  • Vote above, so the next months go to the models you actually want.
